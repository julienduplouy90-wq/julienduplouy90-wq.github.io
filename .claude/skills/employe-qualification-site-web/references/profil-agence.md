# Profil de l'agence

Ce profil se remplit une seule fois. L'employé qualification le lit avant chaque mission : c'est lui qui lui dit pour quelle agence il travaille, ce qu'elle vend, à qui, et ce qu'elle peut prouver. Il est pré-réglé pour une agence qui vend des sites web : change l'offre et le prix si tu vends autre chose.

Le plus simple : enregistrer ce fichier dans le projet Claude de l'agence (ou dans le dossier de travail) sous le nom `profil-agence.md`. Si le profil manque, l'employé pose les questions essentielles en une seule fois, puis propose de l'enregistrer.
