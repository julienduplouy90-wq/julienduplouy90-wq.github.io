# Roadmap

Estimations en **heures de votre temps** (supervision, tests, contenus) ; le développement est réalisé par l'assistant.

## Phase 1 — MVP local ✅ (cette livraison, ~3 h de supervision)
Socle, schéma, dashboard, projets, sites (prévisualisation), formulaire, qualification, CRM + import CSV, distribution manuelle, finances, RGPD de base, tests.

## Phase 2 — Mise en ligne du pilote (≈ 6–8 h, coût ≈ 10–30 €)
1. Valider les décisions ⏳ (`DECISIONS.md` : hébergement, marque, domaine, conservation).
2. Importer les 20 partenaires, saisir les retours de la campagne Gmail.
3. Compléter mentions légales / confidentialité ; relire tous les textes du site.
4. Créer le projet Supabase (gratuit), appliquer migrations + RLS, configurer l'hébergement **après votre accord**.
5. Domaine (≈ 10–15 €/an), `SITE_DOMAINS`, publication puis activation de l'indexation.
6. Google Search Console (vérification + sitemap). Test complet de bout en bout avec une fausse demande.

## Phase 3 — Premiers revenus (≈ 2–3 h/semaine)
Notification e-mail **à vous** lors d'une nouvelle demande · modèle de facture simple · suivi des relances partenaires ·
pages de contenu réellement utiles (rédigées/relues) · mesure d'audience sans cookie.

## Phase 4 — Industrialisation (après validation du modèle)
Duplication de projet · 2e niche · pages géographiques à contenu réel · Supabase Auth + multi-utilisateur · portail partenaire ·
qualification assistée par IA · Search Console / positions · Google Ads.

## Phase 5 — SaaS
Stripe (abonnements, crédits) · marque blanche · domaines personnalisés · internationalisation · recherche de niches et analyse concurrentielle.
